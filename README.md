# 🚀 Momentum App (노마드코더 바닐라 JS)

노마드코더 **[바닐라 JS로 크롬 앱 만들기]** 강의를 수강하며 제작하는 크롬 확장프로그램형 웹 앱 프로젝트입니다.  
HTML, CSS, Pure JavaScript만을 사용하여 기본 구조부터 인터랙티브한 기능까지 직접 구현합니다.

---

## 🛠️ 기술 스택 (Tech Stack)

- **HTML5** (`index.html`) - 웹 페이지의 기본 구조 작성
- **CSS3** (`style.css`) - 스타일링 및 레이아웃 정의
- **Vanilla JavaScript** (`app.js`) - 동적 기능 및 로직 구현

---

## 📁 프로젝트 구조 (Project Structure)

```text
Nico_javascript/
├── chapter 01/
│   ├── index.html   # 기본 메인 HTML 문서
│   ├── style.css    # 웹 스타일시트
│   └── app.js       # 자바스크립트 스크립트 파일
└── README.md

📝 파일별 역할
index.html: CSS(style.css)와 JS(app.js)를 불러오고, Momentum 앱의 UI 틀을 형성합니다.

style.css: 배경색 및 요소들의 디자인을 담당합니다.

app.js: 브라우저 콘솔 출력, 사용자 이벤트 처리, 시계/날씨/투두리스트 등의 로직을 처리합니다.
