# 🚀 Momentum App (노마드코더 바닐라 JS)

노마드코더 **[바닐라 JS로 크롬 앱 만들기]** 강의를 수강하며 제작하는 크롬 확장프로그램형 웹 앱 프로젝트입니다.  
HTML, CSS, Pure JavaScript만을 사용하여 기본 구조부터 인터랙티브한 기능까지 직접 구현합니다.

---

## 🛠️ 기술 스택 (Tech Stack)

- **HTML5** (`index.html`) - 웹 페이지의 기본 구조 작성
- **CSS3** (`style.css`) - 스타일링 및 레이아웃 정의
- **Vanilla JavaScript** (`app.js`) - 동적 기능 및 로직 구현

---
